# 错题本

一个错误只记录四件最重要的事：

> 现象 → 原因 → 修法 → 下次怎么认出来

## 2. 原因

真正的原因是什么？

>

不要只写“代码写错了”，要具体到：

- 哪个变量
- 哪一行
- 哪个类型
- 哪个作用域
- 哪个路径
- 哪个条件
- 哪个 API 用法
